# Contributing to MorseTrainer

Thank you for your interest in contributing to **MorseTrainer**!

We welcome contributions of all kinds: bug fixes, feature requests, documentation improvements, UI enhancements, and new ideas.

---

## Code of Conduct

Please be respectful, inclusive, and collaborative in all interactions within this project.

---

## How to Contribute

### Reporting Bugs
1. Check existing [Issues](https://github.com/sputlab/morsetrainer/issues) to avoid duplicates.
2. If the bug has not been reported, open a new issue using the **Bug Report** template.
3. Include device, operating system, and browser version, along with reproduction steps.

### Suggesting Enhancements
1. Open an issue using the **Feature Request** template.
2. Describe the feature, motivation, and proposed user experience.

### Submitting Pull Requests
1. Fork the repository.
2. Create a new topic branch:
   ```bash
   git checkout -b feature/my-new-feature
   ```
3. Make your changes.
   - Keep code clean, readable, and consistent with the existing style.
   - Remember this project has **zero build steps** and **zero external dependencies**. All logic is written in vanilla HTML, CSS, and JavaScript.
4. Test thoroughly in modern browsers (Chrome, Firefox, Safari).
5. Commit your changes with clear, descriptive commit messages:
   ```bash
   git commit -m "feat: add Koch method training mode"
   ```
6. Push to your fork:
   ```bash
   git push origin feature/my-new-feature
   ```
7. Open a Pull Request targeting the `main` branch.

---

Thank you for helping make MorseTrainer better!
